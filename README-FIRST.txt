Helldivers 2 Chaos Slot Machine - Windows x64

The recommended download is the versioned Setup .exe. It is a complete offline
installer: after downloading it, installation does not require internet access,
Node.js, npm, or Python. You can compare it against its matching .sha256 file
before running it.

If you downloaded the portable ZIP instead:

1. Optional: compare the ZIP against its matching .sha256 checksum before extracting.
2. Extract the entire ZIP before running the app.
3. Open the extracted folder.
4. Double-click "Helldivers 2 Chaos Slot Machine.exe".
5. Do not move only the .exe. It depends on the Electron runtime files and resources next to it.

Saved information is stored in your Windows user data folder for this app:
   %APPDATA%\Helldivers 2 Chaos Slot Machine\state.json

After the rename, a valid save from the previous "Helldivers 2 Chaos Roulette"
data folder is copied automatically when no new save exists. The old files are
kept unchanged. Older JSON exports can also be imported from Results.

Use Results -> Export JSON to create a portable backup, and Results -> Import JSON to restore one.
