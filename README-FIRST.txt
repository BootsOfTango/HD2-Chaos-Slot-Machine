HD2 CHAOS SLOT MACHINE
Windows x64 | 1.0 | Unofficial fan-made solo companion

ABOUT THIS GUIDE
---------------
This guide describes HD2 Chaos Slot Machine 1.0. The same package is used
for local acceptance and the approved GitHub download; no stream-only build.
Source preparation alone does not mean a download has been published.
Windows may show internal compatibility version 1.1.14; that is expected.
No Steam login, game-memory access or game-control automation is required.
The app does not launch missions, grant equipment or read your game account.

INSTALL ONCE, THEN USE YOUR SHORTCUT
----------------------------------
1. Use this project's GitHub Releases page:
   https://github.com/BootsOfTango/HD2-Chaos-Slot-Machine/releases
2. Read that release's notes, then choose its Windows x64 Setup .exe under
   Assets. An older release may have an older name and fewer features.
   Do not choose Source code or Code -> Download ZIP to play.
3. Close any running copy before installing/upgrading. Keep the normal
   Windows apps location, not your Desktop, download or source folder.
4. Open HD2 Chaos Slot Machine from Start or Setup's desktop shortcut.
   You do not need to run Setup each time.

Setup includes the images and runtime. No Git, Node.js, npm or Python needed.
Leave the installed supporting files together. A developer's .lnk shortcut
will not work on another PC; Setup creates the correct shortcuts for you.

Optional portable ZIP: no Setup needed. Download the release's app ZIP,
extract the ENTIRE ZIP, then run HD2 Chaos Slot Machine.exe inside it.
Do not run inside the ZIP or move just the EXE away from DLLs/resources.
Portable means no installation, not USB-contained saves: installed and
portable copies normally share the same Windows user-data folder.
Use one copy at a time.

FIRST RUN / ONE SOLO DIVE
------------------------
1. Dismiss the short Just for fun notice with Let's dive.
2. Armory: review Owned and Include in rolls / Enabled. Owned means you
   unlocked it in game; Included means this app may roll it. Enable only
   equipment you have. A Warbond purchase does not unlock all its items.
3. Spin -> SPIN LOADOUT. Choose difficulty and wait for the reels.
4. Use SPECIAL EVENT: REROLL if offered, then LOCK LOADOUT when ready.
5. Keep the planet, REROLL PLANET, or open MANUALLY SEARCH FOR PLANET?
   Choose a planet on the map or list, then CONFIRM PLANET.
6. Choose a mission icon or Roll mission, then Play this. Verify the
   mission is actually available in your game; these are suggestions.
7. Enter your player name -> CONFIRM PLAYER AND CREATE CARD.
8. Play your solo dive in Helldivers 2, then open the pending card in Results.

Starting another Spin replaces the unfinished spin. Unfinished equipment
spins do not survive restart; created Result cards and supported settings do.
The themed Seed name is a codename, not a code that recreates the roll.
Names reflect equipment/context and avoid names already in your saved
collection; they are not globally unique or predictions of effectiveness.

ENTER RESULTS AND SAVE
----------------------
The card asks one question at a time. Use Next / Back, then review and Edit
any answer before saving. Use real score-screen numbers; 0 means none.
Mission time is decimal minutes: 12.5 = 12 minutes 30 seconds.
Record side objectives completed AND total available. No samples required.

Cancel or Escape discards the unsaved entry session, not the existing card.
Tick the review checkbox, then Save & lock only after checking everything.
Numbers, outcomes and the original run note become permanent.
You can still add comments later. Expand Loadout, Stats or Scoring for details.
Saved cards include a planet visual and sector locator where data allows;
the locator is reference geography, not a live or historical territory replay.

Solo radar axes: Firepower, Precision, Survivability, Speed, Utility, Mission.
Utility uses completed / available side objectives; zero available means N/A.
Ratings use provisional app benchmarks, not official game balance measurements.
Rank groups comparable solo runs and orders mission successes before rating.
Incomplete/unranked cards do not enter Solo ranking. Extraction is separate.
Legacy scores remain separate and frozen; Compare/equipment analytics are
Legacy-only. Solo profiles can be compared side by side in Rank.
Use Results > REVIEW CARD RULES to preview updates and incomplete-card removals.
Nothing changes automatically. LATER keeps old ratings separate. BACK UP & APPLY
first verifies a recovery copy, then updates complete cards from recorded inputs.
Only listed, genuinely incomplete finalized cards are removed; pending cards stay.
Invalid or unsupported data blocks the update. Original ratings/records, entered
numbers, notes and later comments are retained for kept cards, including exports.
OPEN SAVE FOLDER contains card-upgrades/<unique-id>/before.json and its checksum
manifest, outside the 20-file rolling backup limit. These files survive app updates.
Review newer dives/comments and export current data before importing a backup:
import replaces the whole collection, not a merge. No automatic rollback is done.
JSON transfer still has a 32 MiB/10,000-card limit; it never truncates history.
Large native backups need assisted recovery. Browser copies stay in browser storage.
History-bearing saves use format 2; do not edit them with an older app.
Do not open newer-format saves with an older app.

ARMORY AND OWNERSHIP
-------------------
Search items, aliases, roles or Warbonds; use category/Warbond sections and
Owned/Included filters. CLEAR FILTERS restores hidden search results.
Filters change what you see, not what is eligible. Bulk controls apply to
the full Warbond group, not just visible search results. Search text resets
on launch; supported browsing preferences are saved/exported.

This reviewed catalog has 214 items and 25 Warbond groups. It is bundled,
not automatically updated when the game adds gear. New paid/reward additions
start excluded; existing ownership choices are preserved.
Castellan's Creed includes 40-K Meltagun as a SUPPORT STRATAGEM.
Ironclad Democracy has seven additions; LAS-12 Sai is a separate Superstore
primary. Eagle Gas Airstrike is a campaign reward, distinct from Orbital Gas
Strike. Confirm your actual unlocks; the app cannot check purchases/rewards.
An empty category does not silently re-enable excluded/unowned items.

PLANET MAP AND LIVE DATA
-----------------------
Drag from blank space OR a planet to pan; wheel/pinch zooms. A normal click
inspects a planet. Search to focus, or use Use list instead.
Eligible only starts checked each time the chooser opens. Inactive/context
planets are not automatically selectable. Sector shades and faction colors
are approximate, not exact in-game borders. Supply links show available data.

Hover, focus or inspect a planet for environment/weather and Reported
activity. Reviewed community reports can show Hive Lords, Jet Brigade,
enemy surges, Terminid strains and SEAF presence. Missing/unreviewed reports
do NOT mean no special enemies, and badges do not guarantee an encounter.
Environment labels are not weather measured at this instant.

- Refresh at startup and every five minutes while open and visible.
- While the map is open and visible, refresh checks run once per minute.
- Stale reconnect/resume and REFRESH WAR DATA can request updates.
- Manual refresh has a 30-second cooldown; failures/rate limits delay retries.
- No per-hover requests or closed-app updates.
- Community feeds can lag the game; retrieval times are not proof of when
  the game changed. Check timestamps and your in-game map before diving.
- Cached/bundled data is not confirmed currently playable.
- Planet rolls span enabled active planets across factions. The planet sets
  the enemy; rerolls avoid repeats when another eligible planet exists.
- Refresh does not silently change locked runs or historical Results.
  Unfinished incompatible mission choices can require reconfirmation.
- Refresh does not install new equipment catalogs or app updates.

MISSIONS: SUGGESTIONS, NOT YOUR EXACT OPERATION
---------------------------------------------
The bundled catalog has 60 mission identities with yellow/gold game-image
icons; coverage is partial, not a complete list of all current game content.
Availability uses known faction, difficulty and campaign context.
It does not read your ship's operation screen; event/region restrictions
may require your confirmation. Custom/unknown missions use fallback symbols.

Optional: Armory -> Advanced -> Mission tools -> My operation.
Choose/confirm a planet in Spin first, then check the missions you actually
see in game. Add missing mission accepts an explicit scoring category;
duration alone does not set scoring. Random/manual choices use the same
confirmed shortlist. Empty lists remain empty until changed or reset.
Use Reset to suggestions to leave the shortlist, or Back to mission to return.
Planet/difficulty/event/catalog changes may require reconfirmation.

WINDOW CONTROLS
---------------
Normal launch starts fullscreen. F11 or Fullscreen toggles windowed mode.
Escape closes the open dialog first; otherwise it exits fullscreen.
Small windows keep the desktop layout: use scrollbars, wheel/trackpad, or
Space + drag on empty background. Map dragging is separate; no Space needed.

BACKUPS, UPDATES AND WARNINGS
----------------------------
Results -> EXPORT JSON: back up before updating, importing or changing PCs.
Keep the backup outside the app folder and keep it until you verify restoration.
Results -> IMPORT JSON: can replace cards/settings; export current data first.
Supported transfers allow up to 32 MiB and 10,000 cards, with complexity limits.
Oversized transfers are refused, not truncated. Desktop autosaves do not have
that transfer limit. Browser storage may fill earlier.
Close the app before running new Setup; do not delete your save folder.

Results -> OPEN SAVE FOLDER opens the active profile. Normal installed/
portable location: %APPDATA%\Helldivers 2 Chaos Slot Machine
state.json and automatic backup/recovery files live there. The developer's
review shortcut uses a separate profile: use OPEN SAVE FOLDER to identify it.
Backups and exports can contain player names/history; review before sharing.
CLEAR ALL DATA is a reset, not a routine repair.

If a yellow save warning appears: keep the app open, use Retry saving or
Export session JSON. Close without saving discards unsaved session changes
after confirmation. If startup cannot safely load an existing save, the app
protects it from overwrite. Close and resolve the problem/use a compatible
newer app; do not delete the original or recovery files to bypass protection.

This release is unsigned. Windows may show an unknown-publisher
or SmartScreen warning. Check the release source, signature status and
matching .sha256 checksum. A checksum detects changed bytes, not malware.
Do not disable antivirus or Windows protection; report unexpected warnings.

No sound? Check Windows volume and the selected output device.
Software rendering may use more CPU. If you encounter freezing, display
trouble or a blue screen, stop and report the time, build and steps.
Do not repeatedly reproduce a crash. No safety/crash-free guarantee is made.
