# Full-name project mark

The `hd2-chaos-slot-machine.svg` mark is generated from original rectangle and bitmap-letter geometry in `scripts/brand-art.js`. It uses yellow/black lettering and a dark slot-machine silhouette. No game, publisher or crossover images or external font files were used. It is a project mark, not an official HELLDIVERS logo, permission grant or assertion of exclusive rights over AI-assisted output.

`npm run prepare:icons` produces the same SVG, a 256px PNG and a multi-size Windows ICO. Full words are legible at larger sizes; the smallest Windows sizes primarily convey the silhouette, not readable seven-letter text. Accessible UI text and Windows metadata preserve the complete name at every size.

The previous `hd2csm-emblem.png` is retained unchanged as a recoverable source asset. It is no longer the header, favicon or icon-generator input. Existing installed builds still contain their original artwork.
