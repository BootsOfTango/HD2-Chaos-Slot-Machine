# Planet illustrations

Original code-native SVG globe illustrations created for this project on September 18, 2026.
Self-contained paths, gradients and circles; no downloaded, traced or embedded game artwork,
AI-generated bitmap, remote dependency, font, animation or GPU filter.

These are representative **biome-family illustrations**, not official Helldivers 2 planet
renders, geographic maps, photographs, or a claim about exact current planet appearance.
The mapping uses only the supplied biome label, never faction, weather, a planet-name guess,
or an arbitrary imported URL. Unknown/new/localized biome labels receive a neutral globe.
Several biomes intentionally share artwork. Images carry no mission or playability data.
